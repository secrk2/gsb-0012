# 工瞳 · 工地人员实名制、不安全行为预警与出勤分账平台

面向住建场景的工地安全产品骨架。当前包含三大模块：**工地作战台**（在场漏斗 / 今日应培训 / 隐患 / 告警红点 / 本月出勤率）、**人员档案**（实名制状态机 / 姓名脱敏 / 查看留痕）与**出勤打卡与工资分账**（闸机+手机多源合并 / 周月甘特 / 合同版本单价 / 结算冻结 / 部分发放 / 复核补差），支持离线作业与五类角色数据隔离。

## 一键启动

```bash
docker compose up --build
```

- 前端（Nginx，反代 `/api` → 后端）：http://localhost:8105
- 后端（Go，SQLite 落盘在 `gt-data` 卷）：http://localhost:7105/api/healthz

首次启动自动灌入演示数据：**3 个工地、21 名人员（覆盖待入场/在场/请假离场/退场/黑名单全部状态）、6 个账号、培训/隐患/告警数据**，另含 **2026-06 起的打卡流水（双闸机/手机+闸机合并样本、机械班半天班）、合同 v1→v3 单价版本、6/7/8 月结算冻结（8 月部分发放且有 1 笔结算后代打卡差异待复核）**。

## 需求点对照

| 需求 | 实现 |
|---|---|
| 人员状态机 | `待入场→在场→请假离场→退场→黑名单`，有向边见 `backend/models.go`；非法回退返回 409 + 中文原因（如「已退场，状态不可回退」） |
| 实名制入场 | `待入场→在场` 必须同时完成刷脸 + 身份证核验，否则 422 拦截 |
| 姓名脱敏 | 列表/详情默认 `张* · 工号`，身份证/手机号同步脱敏 |
| 查看全名 | 仅总包/监理，弹窗二次确认 + 必填理由，写 `reveal_logs` 留痕，监管员可追溯 |
| 作战台 | 在场漏斗、今日应培训、未闭环隐患、告警红点（点击消红点/全部已读） |
| 响应式 | 1440 三栏 / 1024 两栏 / 390 单栏 + 底部导航（断点 1280/768） |
| 数据隔离 | 工人越权看他人档案 → 403 错误态页面（非空白）；班组长限本班组；总包/监理限本工地 |
| 离线作业 | 离线横幅 + 缓存数据打「离线缓存·更新于 xx」戳；变更进 localStorage 队列 |
| 恢复合并 | 恢复后 `POST /api/sync/batch` 批量同步，按 `client_op_id` 幂等去重（唯一索引 + 同事务写入），状态已被他人推进的返回 `conflict` + 当前状态，前端提示并刷新 |
| 出勤打卡 | 闸机/手机上报原始流水：同设备同人同方向3分钟内去重；同人同天双闸机或手机+闸机聚合为**一条**日记录（流水留底、结论一条） |
| 出勤判定 | 每人每天判 出勤/缺勤/迟到/早退（可迟到且早退），请假/未入场/已退场/周日休息/打卡作废 分列；缺上班/下班卡分别按迟到/早退估算 |
| 出勤率双口径 | ① 实际出勤天÷应出勤天（人到就算，半天班仍算1天）② 有效打卡工时÷排班工时（半天班4h、扣午休）。半天班多的班组两口径会相反，口径公式写在作战台/甘特/导出三处 |
| 甘特三端 | 桌面整表甘特（左列吸住横滑）/ 平板左名单右单人条 / 手机竖向人员卡；周、月两档切换；三种空态分开：加载失败、该人无打卡、打卡全作废 |
| 工资分账 | 月工资=出勤工日(有效工时÷8)×日单价；合同版本单价只对生效月起作用；结算瞬间冻结工日/单价版本/金额快照，新单价不追溯历史月 |
| 部分发放 | `payroll_payments` 独立流水，可多次部分发放；任何重算、复核补差都不冲销已发部分 |
| 结算后改打卡 | 必须二次确认+填原因留痕；冻结金额与已发不动，只打「待复核」差异并给出实时对照金额；总包可补差或维持，补差也留痕 |
| 离线打卡 | 手机离线打卡进 localStorage 队列，恢复后逐笔带 `client_op_id` 幂等补传，多源同日仍在服务端合并 |

## 离线能力演示

1. 用 `sub_leader` 登录，打开某工人档案；
2. 浏览器 DevTools → Network → 勾选 **Offline**；
3. 顶部出现离线横幅；执行「办理请假」→ 提示「已离线排队」；
4. 取消 Offline → 自动批量同步，提示已同步/去重；
5. 若离线期间他人已变更该工人状态（可开另一浏览器操作），同步时提示冲突并按服务器最新状态合并。

## 本地开发（不用 Docker）

```bash
# 后端（Go ≥ 1.22）
cd backend && go run .            # 监听 :7105，自动建库+种子数据

# 前端（任意静态服务器，需把 /api 代理到 7105，或直接改 js/api.js 中路径）
cd frontend/static && python3 -m http.server 8105
```

## API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/login` | 登录（bcrypt 校验，12h 会话） |
| GET | `/api/dashboard?site_id=` | 作战台聚合 |
| GET | `/api/workers?status=&q=` | 人员列表（按角色隔离，脱敏） |
| GET | `/api/workers/{id}` / `/api/workers/me` | 档案详情 + 时间线 + 留痕 |
| POST | `/api/workers/{id}/transition` | 状态变更（状态机校验 + `client_op_id` 幂等） |
| POST | `/api/workers/{id}/reveal-name` | 查看全名（总包/监理 + 理由 + 留痕） |
| POST | `/api/sync/batch` | 离线批量同步（applied/duplicate/conflict） |
| POST | `/api/alerts/{id}/read`、`/api/alerts/read-all` | 告警消红点 |
| POST | `/api/attendance/punches` | 打卡上报（闸机/手机，3分钟同源去重 + `client_op_id` 幂等） |
| GET | `/api/attendance/gantt` | 周/月出勤甘特（`view=week|month&date=&month=&team=&caliber=days|hours`） |
| GET | `/api/attendance/export` | 出勤 CSV（表头写明当前口径公式，两口径都给列） |
| GET | `/api/workers/{id}/punches?date=` | 某人某日打卡流水与该月是否已冻结 |
| POST | `/api/punches/{id}/void`、`/restore` | 作废/恢复（已结算月需 `confirm_settled` + 原因留痕） |
| GET/POST | `/api/contracts` | 合同日单价版本（新版本生效月不可早于已结算月） |
| GET | `/api/payroll?month=` | 月分账（未结算实时算/已结算读冻结快照+已发+补差+差异） |
| POST | `/api/payroll/settle` | 月结算冻结（需 `confirm`） |
| POST | `/api/payroll/pay` | 登记发放（可部分发放，独立流水不冲销） |
| POST | `/api/payroll/review` | 结算后差异复核（`apply`补差/`keep`维持，原因留痕） |
| GET | `/api/payroll/export` | 分账 CSV（冻结/补差/应发/已发/待发） |
